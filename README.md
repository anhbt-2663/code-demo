# code-demo

Repo **thử nghiệm**, dùng để chạy thử quy trình tự động hoá liên kết Spec/Design
vào Story trên GitHub. Không chứa mã nguồn sản phẩm nào.

Cặp đôi: [anhbt-2663/pm-demo](https://github.com/anhbt-2663/pm-demo) — nơi chứa issue.

| Thư mục | Nội dung |
|---|---|
| `Spec/` | spec màn hình mẫu (`9-1 Notice List`) |
| `Design/` | design mẫu |
| `.github/workflows/` | 3 workflow: cổng kiểm link PR, bot ghi story, cron quét |
| `.github/scripts/` | script của bot |

Xoá repo này sau khi thử xong.
